Given

Claim
\(\displaystyle \sin\left(2 \, z\right) = 2 \, \sin z \, \cos z\)
Expected
true equal at every admissible point

the two sides are equal at every admissible point

Lean proof: included

(case trig-double-01
  (category identities)
  (source claude-trig-2026-10 "first committed in cd62696")

  (var z complex)
  (ask (= (sin (* 2 z)) (* 2 (* (sin z) (cos z)))))
  (expect true)
  (lean-proof "simp [Complex.sin_two_mul, mul_assoc]"))

trig-double-02 Lean-verified

Given
\(x \in \mathbb{R},\quad x > 0,\quad x < 1\)
Claim
\(\displaystyle \sin\left(2 \, x\right) \neq 2 \, \sin x\)
Expected
false unequal at every admissible point (e.g. at \(x = \frac{1}{2}\))

the two sides differ at every admissible point

witness (false): \(x = \frac{1}{2}\)

sin 2x = 2 sin x iff sin x (cos x - 1) = 0: never on (0, 1).

Lean proof: included

(case trig-double-02
  (category identities)
  (source claude-trig-2026-10 "first committed in cd62696")

  (var x real)
  (assume (positive x))
  (assume (< x 1))
  (ask (= (sin (* 2 x)) (* 2 (sin x))))
  (expect false)
  (witness false (x 1/2))
  (lean-proof "obtain ⟨r, rfl⟩ := AE.IsReal.exists hd0; simp at h0 h1; have hs := Real.sin_pos_of_pos_of_lt_pi h0 (by linarith [Real.pi_gt_three]); have hc : Real.cos r < 1 := (by simpa using Real.cos_lt_cos_of_nonneg_of_le_pi le_rfl (by linarith [Real.pi_gt_three]) h0); refine ⟨by simp, ?_⟩; rw [AE.sin_eq, AE.sin_eq, Complex.sin_two_mul, ← Complex.ofReal_sin, ← Complex.ofReal_cos]; exact_mod_cast (by nlinarith : 2 * Real.sin r * Real.cos r ≠ 2 * Real.sin r)")

  (note "sin 2x = 2 sin x iff sin x (cos x - 1) = 0: never on (0, 1)."))

trig-sqrt-01 Lean-verified

Given
\(x \in \mathbb{R}\)
Claim
\(\displaystyle \sqrt{1 - \sin x \, \sin x} \overset{?}{=} \cos x\)
Expected
contingent true at \(x = 0\); false at \(x = 3\)

equal at some admissible points, different at others

witness (true): \(x = 0\)

witness (false): \(x = 3\)

sqrt(cos^2) is |cos x|, which is cos x only where cos x >= 0.

Lean proof: included

(case trig-sqrt-01
  (category identities)
  (source claude-trig-2026-10 "first committed in cd62696")

  (var x real)
  (ask (= (sqrt (- 1 (* (sin x) (sin x)))) (cos x)))
  (expect contingent)
  (witness true (x 0) (lean-proof "norm_num [AE.sqrt]"))
  (witness false (x 3)
    (lean-proof "have hc : Real.cos 3 < 0 := Real.cos_neg_of_pi_div_two_lt_of_lt (by linarith [Real.pi_lt_d2]) (by linarith [Real.pi_gt_three]); refine ⟨by simp, by simp, ?_⟩; rw [AE.sin_eq, AE.cos_eq, ← Complex.ofReal_ofNat, ← Complex.ofReal_sin, ← Complex.ofReal_cos, ← Complex.ofReal_mul, ← Complex.ofReal_one, ← Complex.ofReal_sub, AE.sqrt_ofReal (by nlinarith [Real.sin_sq_le_one 3])]; exact_mod_cast (hc.trans_le (Real.sqrt_nonneg _)).ne'"))

  (note "sqrt(cos^2) is |cos x|, which is cos x only where cos x >= 0."))
