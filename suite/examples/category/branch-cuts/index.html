Claim
\(\displaystyle \operatorname{atan2}\left(y, x\right) = \arctan\left(\frac{y}{x}\right)\)
Expected
true equal at every admissible point

the two sides are equal at every admissible point

Lean proof: included

(case demo-atan2-01
  (category branch-cuts)
  (source claude-demo-2026-10 "first committed in 2f2f2cd")

  (var x real)
  (var y real)
  (assume (positive x))
  (ask (= (atan2 y x) (atan (/ y x))))
  (expect true)
  (lean-proof "obtain ⟨r, rfl⟩ := hd0.exists; obtain ⟨s, rfl⟩ := hd1.exists; simp at h0; obtain ⟨a1, a2⟩ := abs_lt.1 (Complex.abs_arg_lt_pi_div_two_iff.2 (Or.inl (by simpa : 0 < ((r:ℂ) + Complex.I * s).re))); refine ⟨by simp [AE.atan2.D, h0.ne', Complex.ext_iff], ?_⟩; rw [show (s:ℂ) * AE.inv r = ↑(s / r) by simp [div_eq_mul_inv], AE.atan_ofReal, AE.atan2, AE.im, AE.log, Complex.log_im, AE.i, ← Real.arctan_tan a1 a2, Complex.tan_arg]; simp"))

demo-log-02 Lean-verified

Given
\(z, w \in \mathbb{C},\quad z \neq 0,\quad w \neq 0\)
Claim
\(\displaystyle \log\left(z \, w\right) \overset{?}{=} \log z + \log w\)
Expected
contingent true at \(z = 1, w = 1\); false at \(z = -1, w = -1\)

equal at some admissible points, different at others

witness (true): \(z = 1, w = 1\)

witness (false): \(z = -1, w = -1\)

Lean proof: included

(case demo-log-02
  (category branch-cuts)
  (source claude-demo-2026-10 "first committed in 2f2f2cd")

  (var z complex)
  (var w complex)
  (assume (nonzero z))
  (assume (nonzero w))
  (ask (= (log (* z w)) (+ (log z) (log w))))
  (expect contingent)
  (witness true (z 1) (w 1) (lean-proof "simp [AE.nonzero, AE.nonzero.D, AE.log]"))
  (witness false (z -1) (w -1)
    (lean-proof "refine ⟨by simp [AE.nonzero, AE.nonzero.D], by simp [AE.nonzero, AE.nonzero.D], by norm_num, fun h => ?_⟩; have h1 := congrArg Complex.im h; simp [AE.log, Complex.log_neg_one] at h1; linarith [Real.pi_pos]")))

demo-log-03 Lean-verified

Given
\(x \in \mathbb{R},\quad x < 0\)
Claim
\(\displaystyle \log x \neq \log\left(-x\right)\)
Expected
false unequal at every admissible point (e.g. at \(x = -1\))

the two sides differ at every admissible point

witness (false): \(x = -1\)

log x has imaginary part pi for x < 0, while log(-x) is real.

Lean proof: included

(case demo-log-03
  (category branch-cuts)
  (source claude-demo-2026-10 "first committed in 3e20cae")

  (var x real)
  (assume (negative x))
  (ask (= (log x) (log (- x))))
  (expect false)
  (witness false (x -1)
    (lean-proof "refine ⟨by simp [AE.IsReal], by simp [AE.negative, AE.negative.D, AE.real, AE.real.D, AE.lt, AE.re, AE.im, AE.IsReal], by norm_num, ?_⟩; simp [AE.log, Complex.log_neg_one, Real.pi_ne_zero, Complex.I_ne_zero]"))
  (lean-proof "have hx : x.im = 0 := hd0; have hr : x.re < 0 := (by simpa [AE.negative, AE.lt, AE.re] using h0.2.2); have e : x = ((x.re : ℝ) : ℂ) := Complex.ext (by simp) (by simp [hx]); refine ⟨⟨fun h => by simp [h] at hr, fun h => by simp [neg_eq_zero.mp h] at hr⟩, fun h => ?_⟩; have h1 := congrArg Complex.im h; rw [e, AE.log, AE.log, ← Complex.ofReal_neg, AE.log_neg_real _ hr, Complex.log_im, Complex.arg_ofReal_of_nonneg (by linarith)] at h1; exact Real.pi_ne_zero h1")

  (note "log x has imaginary part pi for x < 0, while log(-x) is real."))
